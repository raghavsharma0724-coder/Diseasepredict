About The Project

Project Overview

What This System Does

MediPredict AI takes a user's age, gender, and selected symptoms as input, processes them through a trained classification model, and predicts the most probable disease. The result page then provides a confidence score, risk level, disease description, causes, precautions, lifestyle guidance, and a recommended medical specialist — with a one-click link to find nearby hospitals.

The goal is to demonstrate practical application of supervised machine learning within a professional, deployable Flask web application.

Machine Learning Pipeline

How The Model Was Built

1. Data Preparation

A structured disease-symptom dataset ({{ metrics.num_symptoms }} symptoms, {{ metrics.num_diseases }} diseases) was cleaned, one-hot encoded for symptoms, and label-encoded for Gender and Disease.

2. Train-Test Split

Data was split 80/20 ({{ metrics.train_size }} training rows, {{ metrics.test_size }} testing rows) using stratified sampling to preserve class balance.

3. Model Training

Three algorithms were trained and compared: Random Forest, Decision Tree, and Logistic Regression.

4. Evaluation

Each model was scored on Accuracy, Precision, Recall, and F1 Score using the held-out test set.

5. Best Model Selection

The model with the highest test accuracy was automatically selected and saved for deployment.

6. Deployment

The trained model was serialized with Pickle and integrated into a Flask web application for real-time predictions.
